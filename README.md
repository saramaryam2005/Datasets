# Datasets

This repository contains datasets and example code demonstrating performance optimization techniques.

## Contents

- `spam.csv` - SMS spam classification dataset (5,572 messages)
- `data_processor_slow.py` - Examples of inefficient code patterns
- `data_processor_optimized.py` - Optimized versions using best practices
- `benchmark.py` - Performance comparison tool
- `PERFORMANCE_GUIDE.md` - Detailed guide on optimization techniques

## Quick Start

Run the performance benchmark to see the improvements:

```bash
python benchmark.py
```

For detailed documentation on performance optimization techniques, see [PERFORMANCE_GUIDE.md](PERFORMANCE_GUIDE.md).
